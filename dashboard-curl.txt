Dashboard API curl examples

Management Dashboard
curl --location '{{api_gateway_url}}/masters/Dashboard/management?company=all-ga&dateRange=cfy' \
  --header 'Authorization: Bearer {{access_token}}' \
  --header 'x-region-id: Meerut'

SuperAdmin Activity Pie Chart
curl --location '{{api_gateway_url}}/masters/DashboardReference/BindDashboardCustomerActivityForSuperAdminJSON' \
  --header 'Authorization: Bearer {{access_token}}' \
  --header 'x-region-id: Meerut'

Optional query parameters:
- company: all-ga or a UI company/GA scope value
- gaId: GA id for complaint filtering when company is not all-ga
- dateRange: cfy, 6m, 12m
- fromDate/toDate: YYYY-MM-DD custom range

Refresh Dashboard Summary
curl --location '{{api_gateway_url}}/masters/Dashboard/refresh-summary' \
  --header 'Authorization: Bearer {{access_token}}' \
  --header 'x-region-id: Meerut' \
  --header 'Content-Type: application/json' \
  --data '{
    "dashboardType": "management",
    "filters": {
      "dateRange": "cfy"
    }
  }'
